# 3D 贪吃蛇 · 小小探险（plus 版）

给孩子玩的 3D 贪吃蛇：五张形状各异的大地图、会追人的果冻小怪兽、金苹果，纯程序化生成的画面与音效。
**单文件、零外部资源、离线可玩**（双击 `index.html` 就能开局）。

这是**加强版**，原版（13×13 标准方形）完整保留在另一个站点，互不影响。

---

## 玩什么

- **5 张地图**，统一 **17×17 包围盒**（289 格），开局在菜单里直接选，选择会记住：

  | 地图 | 形状 | 可走格 | 特点 | 怪兽 |
  | --- | --- | --- | --- | --- |
  | 经典方形 | 17×17 满格 | 289 | 无障碍、无怪兽，最松弛 | 0 |
  | 十字广场 | 十字形 | 189 | 双向长廊，转弯点少 | 3（最高 4） |
  | 菱形花园 | 菱形 | 145 | 四角消失，越走越窄 | 3 |
  | 环形赛道 | 环形 | 240 | 中间实心，要绕圈跑 | 3（最高 4） |
  | 糖果迷宫 | 带障碍 | 233 | 错落分布的彩色糖果块，通道绕来绕去 | 3（最高 4） |

- **两种"过不去"分得很清楚**：
  场地**外轮廓**用粉色围栏收边；场地**内部**的障碍（迷宫块、环形中间）立起彩色糖果方块 ——
  一眼就能看出"这边是墙"，不会误以为围栏里的小院能走进去。

- **怪兽**：果冻质感的圆球小怪，脚下有红色警戒圈。
  出生点至少离蛇头 7 格，距离蛇头 5 格以内会试着追过来（28% 概率仍随机走，留出逃生机会）。
  碰到就结束 —— 撞墙、咬到自己、被怪兽碰到，三种结局各有文案。

- **金苹果**：每吃 4 口，下一个食物就是通体镀金、放大 1.4 倍的金苹果，**+30 分**（普通食物 +10）。
  吃到会弹金色提示、响一段上行琶音。

- **怪兽增援**：分数到线后会**再来一只**小怪兽（普通 90 分 / 困难 60 分，简单档不来），
  弹红色提示 + 一声警告音，右上角地图标签实时更新只数。

- **开局保护**：前 7 个步进内怪兽撞不死蛇 —— 孩子刚开局还在找方向，不该被冤枉地结束。

- **难度递增**：每吃 3~4 口提一档速度；地图越难基础步进越快
  （经典 0.235s / 十字 0.222s / 环形 0.218s / 菱形 0.214s / 迷宫 0.210s，`speedK` 越大越快），
  怪兽节奏也会跟着难度走。

- **操作**：方向键 / `WASD` / 手机滑动 / 屏幕虚拟方向键；空格或 `Esc` 暂停。

- **最高分按地图分开记**（`localStorage`），每张图各自冲榜。

## 技术要点

- three.js **r158 UMD 锁定版**，内联进 HTML，无任何 CDN 依赖。
- **形状系统**：所有地图共用 **17×17** 包围盒 + `Uint8Array` 可通行表；
  出生位、食物、怪兽都只在可通行格上生成，并用 BFS 剪掉不可达孤岛。
- **出生位要算跑道**：遍历所有可通行格 × 4 个方向，打分挑"前方直道最长、越靠中间越好"的那个，
  保证开局至少能直走 6 格。
- **场地是"拼"出来的**：可通行格逐格生成厚板实例（1 次 draw call），
  棋盘纹理按形状做 alpha 遮罩（`alphaTest: 0.5`，不能用 `transparent`）。
- **边界分两类**：从 17×17 边框上的墙格做 BFS，能走到的算"形状外部"→ 插围栏；
  走不到的算"内部障碍"→ 立实心糖果块（同一连通块同色）。围栏只长在外轮廓上。
- **性能**：蛇身、围栏、糖果块全部 `InstancedMesh`；5 张地图实测 60fps，
  draw calls 37~71，三角形 4.9 万~5.4 万，本地首屏可玩约 0.30 秒。
- 纹理（棋盘 / 草地 / 天空 / 小花）全部 canvas 程序化生成；音效用 WebAudio 实时合成。
- 无需构建工具：打开即玩。

## 目录

```
index.html          # 构建产物（单文件，直接打开）
src/template.html   # 页面骨架 + 三个占位符
src/style.css       # 界面样式
src/game.js         # 全部游戏逻辑（地图 / 怪兽 / 渲染 / 音效）
assets/three.min.js # three.js r158
build.py            # 拼装 index.html（含标签配对、无外链、JS 语法自检）
```

重新构建：

```bash
python3 build.py      # 输出 index.html
```

`build.py` 会断言：标签配对、无外部链接、`node --check` 通过。
