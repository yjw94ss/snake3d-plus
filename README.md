# 3D 贪吃蛇 · 小小探险（plus 版）

给孩子玩的 3D 贪吃蛇：五张形状各异的大地图、会追人的果冻小怪兽、金苹果，纯程序化生成的画面与音效。
**单文件、零外部资源、离线可玩**（双击 `index.html` 就能开局）。

这是**加强版**，原版（13×13 标准方形）完整保留在另一个站点，互不影响。

---

## 玩什么

- **5 张地图**，统一 **35×35 包围盒**（1225 格，面积约原 13×13 版的 **7.2 倍**），
  开局在菜单里直接选，选择会记住：

  | 地图 | 形状 | 可走格 | 特点 | 怪兽 |
  | --- | --- | --- | --- | --- |
  | 经典方形 | 35×35 满格 | **1225** | 无障碍、无怪兽，最松弛 | 0 |
  | 十字广场 | 十字形 | **741** | 双向长廊，转弯点少 | 5（最高 6） |
  | 菱形花园 | 菱形 | **613** | 四角消失，越走越窄 | 4（最高 5） |
  | 环形赛道 | 环形 | **1000** | 中间实心，要绕圈跑 | 5（最高 7） |
  | 糖果迷宫 | 带障碍 | **1017** | 错落分布的彩色糖果块，通道绕来绕去 | 5（最高 6） |

- **场地大到一屏放不下 → 相机跟着蛇头走**，格子大小不缩水（始终约 19px 一格，手机竖屏也看得清）；
  同时左下角有**小地图**，苹果、怪兽、自己在哪里一目了然。

- **两种"过不去"分得很清楚**：
  场地**外轮廓**用粉色围栏收边；场地**内部**的障碍（迷宫块、环形中间）立起彩色糖果方块 ——
  一眼就能看出"这边是墙"，不会误以为围栏里的小院能走进去。

- **怪兽**：果冻质感的圆球小怪，脚下有红色警戒圈。
  出生点至少离蛇头 14 格（`MS × 0.4`），距离蛇头 5 格以内会试着追过来（28% 概率仍随机走，留出逃生机会）。
  碰到就结束 —— 撞墙、咬到自己、被怪兽碰到，三种结局各有文案。

- **食物随机但找得到**：落点按「环带」抽距离（3~7 / 5~10 / 8~14 / 11~18 / 14~24 格，权重温和），
  并**排斥最近 6 次出现的食物** —— 同一个角落绝不会连着刷。
  实测食物两两之间平均相距 16 格、45 个 7×7 区块全都有落点，不会老在一个地方打转。
  万一食物落在视野外，屏幕中央会出现一个**指向箭头**，小地图上也有带呼吸光晕的标记。

- **苹果不会长在墙边**：生成时要求落点「四周一圈都空」（到最近墙 / 糖果块 / 场地外 ≥2 格），
  贴墙的苹果会被障碍物挡住一半，看着像卡在缝里。五张图实测 **100% 的食物都离墙 ≥2 格**。

- **金苹果**：每吃 4 口，下一个食物就是通体镀金、放大 1.4 倍的金苹果，**+30 分**（普通食物 +10）。
  吃到会弹金色提示、响一段上行琶音。

- **怪兽增援**：分数到线后会**再来一批**小怪兽（「刚好」90 分 / 「快」60 分 / 「飞快」45 分，
  两个慢档不来），弹红色提示 + 一声警告音，右上角地图标签实时更新只数。

- **开局保护**：前 7 个步进内怪兽撞不死蛇 —— 孩子刚开局还在找方向，不该被冤枉地结束。

- **速度可调（5 档）**：孩子反馈「太快」，所以速度做成一个独立的、随时能改的档位 ——
  菜单里选一次会记住（`localStorage`），**玩到一半觉得快，按暂停就能就地减速，不用重开**。

  | 档位 | 每格 | 约每秒 | 怪兽增援 |
  | --- | --- | --- | --- |
  | 很慢 | 0.44 秒 | 2.3 格 | 不来 |
  | 慢（默认） | 0.36 秒 | 2.8 格 | 不来 |
  | 刚好 | 0.235 秒 | 4.3 格 | 90 分 |
  | 快 | 0.18 秒 | 5.6 格 | 60 分 |
  | 飞快 | 0.15 秒 | 6.7 格 | 45 分 |

  选「慢」时怪兽也跟着慢（节奏按档位缩放 0.85~2.3 倍），不会出现「蛇慢怪兽快」的错位。

- **越来越快**：每吃 3~4 口，步进按比例缩短 2.6%（各档手感一致），最快到该档起步速度的 60%。

- **操作**：方向键 / `WASD` / 手机滑动 / 屏幕虚拟方向键；空格或 `Esc` 暂停。

- **最高分按地图分开记**（`localStorage`），每张图各自冲榜。

## 技术要点

- three.js **r158 UMD 锁定版**，内联进 HTML，无任何 CDN 依赖。
- **形状系统**：所有地图共用 **35×35** 包围盒 + `Uint8Array` 可通行表；
  出生位、食物、怪兽都只在可通行格上生成，并用 BFS 剪掉不可达孤岛。
- **出生位要算跑道**：遍历所有可通行格 × 4 个方向，打分挑"前方直道最长、越靠中间越好"的那个，
  保证开局至少能直走 6 格。
- **场地是"拼"出来的**：可通行格逐格生成厚板实例（1 次 draw call），
  棋盘纹理按形状做 alpha 遮罩（`alphaTest: 0.5`，不能用 `transparent`）。
- **边界分两类**：从 35×35 边框上的墙格做 BFS，能走到的算"形状外部"→ 插围栏；
  走不到的算"内部障碍"→ 立实心糖果块（同一连通块同色，高 0.95 明显凸起）。围栏只长在外轮廓上。
- **相机两种模式**：菜单里装下整张图（俯角 46°，缓慢左右摆动）；
  开局后改为**跟随蛇头**，按"一格约 19px"反解相机距离，并用限位 `camLim` 保证场地最多只外露 4 格草地，
  不会把整块场地甩出屏幕。可见范围由**射线与地面求交的解析解**实测（二分在投影翻转时会跑飞）。
- **阴影相机跟着视野平移**：贴图分辨率固定，摊满全图会糊，所以只覆盖当前视野（`camViewCells × 0.62 + 4`）。
- **小地图**：离屏 canvas 4× 超采样画可通行掩码，每帧限流重绘（≥0.1s 才刷一次），DPR 对齐。
- **食物采样**：环带（annulus）采样而不是圆盘 —— 圆盘会让近处权重层层叠加，落点全挤在蛇头脚下；
  再加上「排斥最近 6 个食物位置」和三级放宽（离墙 ≥2 → ≥1 → 不限，同时放宽历史间距），
  窄地形也挑得出位置。离墙距离用 8 邻域多源 BFS 预先算好（`buildOpenDist`），换图时重建一次。
  食物在视野外时用 `project()` 判断并显示指向箭头（桌面宽屏一屏装下全场，所以只在手机上出现）。
- **速度档**：`SPEEDS` 五项配置（step / floor / reinf），`applySpeed()` 按「档位 + 已吃口数」重算步进，
  所以中途换档既立刻生效、也不会把已经积累的加速清掉或越调越乱。旧难度名 `easy/normal/hard`
  仍映射到最接近的档位，老存档不会失效。
- **性能**：蛇身、围栏、糖果块全部 `InstancedMesh`；5 张地图实测 60fps，
  draw calls 52~95，三角形 9.1 万~10 万，本地首屏可玩约 0.30 秒（线上冷启 <3.2s / 热启 0.32s，gzip 后仅 197KB）。
- 纹理（棋盘 / 草地 / 天空 / 小花）全部 canvas 程序化生成；音效用 WebAudio 实时合成。
- 无需构建工具：打开即玩。

## 目录

```
index.html          # 构建产物（单文件，直接打开）
src/template.html   # 页面骨架 + 三个占位符
src/style.css       # 界面样式
src/game.js         # 全部游戏逻辑（地图 / 怪兽 / 渲染 / 音效）
assets/three.min.js # three.js r158
build.py            # 拼装 index.html（含标签配对、无外链、JS 语法自检）
```

重新构建：

```bash
python3 build.py      # 输出 index.html
```

`build.py` 会断言：标签配对、无外部链接、`node --check` 通过。
